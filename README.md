## 二、怎么用（三步）

1. 双击 `ZhunJing-v8.2.0-win-x64.exe`
2. 若系统弹出「Windows 已保护你的电脑」→ 点 **更多信息** → **仍要运行**
   （单文件程序未做商业代码签名，这是 Windows 对未签名程序的一贯提示）
3. 浏览器会自动打开 `http://127.0.0.1:8787/`，注册一个账号即可开始使用

> 浏览器没自动打开？手动访问上面那个地址即可。
> 想停止服务：关掉那个黑色命令行窗口就行。

## 三、数据在哪、怎么卸载

| 项 | 说明 |
| --- | --- |
| 数据目录 | `%LOCALAPPDATA%\ZhunJing\`（账号库 + 评测证据文件） |
| 端口 | 只监听本机 `127.0.0.1`，不对外暴露，不向任何服务器上传数据 |
| 卸载 | 关闭程序窗口，删除上面的数据目录即可，不留任何残余 |

端口 8787 被占用时程序会自动向后顺延端口（最多试 20 个），并在窗口里给出实际地址。

## 四、能力边界（如实声明，不夸大）

不同评测形态依赖不同的本机环境；缺什么就如实标注，不会用模拟数据冒充真实结果。

| 形态 | 本单文件版的实际能力 |
| --- | --- |
| **网站** | 开箱即用。通过真实 HTTP 执行：真实状态码、真实响应头、真实时延、真实内容校验。渲染 / 控制台 / 截图这类需要真实浏览器内核的检查项，在本机缺少浏览器内核时会被如实标注为「未测成」，不计入失败 |
| **App** | 需要本机有 `adb` 与在线设备；没有则通道不可用并明确提示 |
| **小程序** | 需要本机有微信开发者工具 CLI；没有则通道不可用并明确提示 |
| **AI 工具** | 需要你自己提供模型服务的 API 密钥（密钥只驻内存、不落盘） |

> 另有含真实浏览器内核的完整版可按需提供，体积更大（+150 MB 量级）。
