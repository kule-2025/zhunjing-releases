# 准镜 ZhunJing · 评测平台

> **v8.2.0**（2026-09-29）· 真人实机执行的端到端真实测评平台。
> 一句话差异：**不做"测得更多"，做"测得的结果别人能验"。**

## 产品简介

准镜面向需要对**自有或已授权**的网站、App、小程序、AI 工具开展质量测评的团队：

- **真人方式执行**：像真实用户一样打开、点击、输入，不做无依据的推断式评分；
- **判定式预注册**：测试场景与断言先行定义，结论只由真实执行结果决定；
- **证据可下钻**：每个结论都能逐步展开到断言、截图与哈希证据链，可离线验证；
- **数据严格隔离**：多工作区之间数据结构性隔离，互相不可见。

## 本版本（v8.2.0）主要更新

1. **付费会员体系**：免费版 / 专业版 / 团队版三档，按项目数、月运行数、场景数分级配额，配额校验全部在服务端执行；
2. **双方式登录**：支持**邮箱或用户名**任一方式 + 密码登录（账号密码机制，不使用口令/验证码）；
3. **多项稳定性修复**：测试靶站隔离、访问控制收紧、场景优先级调度、运行重跑与任务取消、能力体检提速等；
4. **会员中心界面**：用量仪表、计划对比、订购记录、会员徽章。

## 使用方式

准镜以「本地评测服务 + 网页控制台」形态交付，安装与运行包通过**项目私有发布渠道**分发（本仓库仅承载公开说明，不含任何程序与源码）。

获得交付包后：

```bash
# 环境要求：Node.js 22 及以上
node server.js
# 浏览器访问 http://127.0.0.1:8787/
```

1. 注册工作区（工作区名 + 用户名 + 邮箱 + 密码）；
2. 使用邮箱或用户名登录；
3. 在「自检靶站」一键体验完整真实测评链路；
4. 在「会员」中心查看用量并按需升级计划。

## 说明与边界（如实声明）

- 当前版本的会员升级采用**开发模式订购单**，尚未接入真实支付网关；
- 部分测试形态（App、小程序、AI 工具）依赖本机对应环境，环境不具备时如实标记为「阻塞」，不产生任何合成结果；
- 本平台仅用于对自有或已授权对象的测评，不提供对第三方产品的公开评测通道。
