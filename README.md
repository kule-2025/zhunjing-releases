# 准镜 ZhunJing · 评测平台

**把地址贴进去，跑一遍真实环境的检查，拿到一份每条结论都能亲自核验的报告。**

准镜是一款面向真实环境的质量评测工具：它像真实用户一样打开、点击、输入，再对每一条结果逐一判定，最终交付一份**带完整证据链的报告**——报告里的每一个结论，都能逐层展开到原始证据，任何人都能离线复核。

**不追求「测得更多」，只追求「测得的结果别人能验」。**

---

## 一、它为你解决什么

评测报告常常只给结论、不给依据：分数好看，却没人能复查，也没人敢直接采信。准镜把「可验证」放在第一位。

| 常见困扰 | 准镜的做法 |
| --- | --- |
| 报告只有结论，无法复查 | 每个结论都能逐层下钻到证据，支持离线核验 |
| 评分靠推断，和真实使用对不上 | 像真实用户一样真实执行，结论只由真实结果决定 |
| 换个人、换个时间再跑，结果对不上 | 同一对象、同一标准，结果可复现 |
| 多团队数据互相可见 | 每个工作区数据严格隔离，互不可见 |

准镜仅用于对**自有或已获授权对象**的测评。

## 五、版本记录

### v8.3.5（当前）
- **登录需勾选协议**：登录页「账号密码」与「邮箱验证码」两种模式各加一个「我已阅读并同意《用户协议》与《隐私政策》」复选框，未勾选强拦截并提示，与注册页口径完全一致
- **密码眼睛图标更清晰**：密码输入框右侧的「显示/隐藏密码」按钮颜色加深、尺寸加大，默认状态肉眼可辨

### v8.3.4
- **双击即开、无命令行窗口**：启动器改为后台自重启模式，双击 exe 后命令行窗口一闪即过，日志全部落到数据目录的 `log.txt`
- **报告可读性提升**：通道不可用（BLOCKED）时不再显示空白或"链断裂"，改为结构化原因说明
- **断言逐条展示**：修复断言与步骤未关联的 bug，每条检查项显示期望值与实测值
- **全项可删除**：项目 / 运行 / 报告三个列表页均加删除按钮，运行详情页支持导出 JSON 与生成分享深链

### v8.3.3
- **desktop 桌面端形态完整接入**：Electron / Chromium 内核的桌面应用可真实启动、真实截图、真实读取 DOM 与控制台错误；非 Chromium 内核或纯命令行程序如实降级为进程级观测（仅验证启动、存活、退出码），绝不伪造 UI 证据

### v8.3.2
- **协议条款重写**：《用户协议》新增「数据服务隔离声明」与「独立开发者免责声明」；《隐私政策》新增「独立开发者声明」并强调跨用户数据严格隔离
- 网络异常提示友好化：后端未启动时不再暴露 `Failed to fetch`，改为「无法连接准镜服务，请确认 ZhunJing.exe 正在运行」

### v8.3.0
- 登录支持**账号密码 / 邮箱验证码**双方式，验证码登录免输密码
- 新增**三步找回密码**：验证邮箱 → 重置密码 → 完成，旧登录自动失效
- 密码框支持**显示 / 隐藏**切换
- 注册需阅读并同意**《用户协议》与《隐私政策》**
- 双击后**页面即刻打开**，等待更短

### v8.2.0
- 交付升级为**一个文件、双击即用**，无需安装或准备任何环境
- **会员体系**：免费 / 专业 / 团队三档，按用量分级
- 登录支持**邮箱或用户名**任一方式
- 打开即用：界面自动打开，无需手动设置
